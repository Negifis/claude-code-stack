# Claude Code Stack

Рабочая конфигурация Claude Code, построенная вокруг одной мысли: **правила в промпте
выветриваются, хуки — нет.**

Инструкции в `CLAUDE.md` носят рекомендательный характер: модель их соблюдает, пока контекст
не разросся, задача не увлекла, а сжатие не выбросило тот самый абзац. Поэтому всё, что не
должно съезжать, вынесено в детерминированные хуки — они читают транскрипт сессии и блокируют
событие `Stop`, — а всё, где нужно суждение, осталось в скиллах.

Здесь лежит принуждающая половина и скиллы, которые с ней работают. Это не шаблон для старта,
а стек, который используется ежедневно на Windows, опубликованный как есть.

## Что внутри

| Каталог | Содержимое |
|---|---|
| `hooks/` | Code Work Gate, система непрерывности и страж плотности комментариев — вместе с регрессионными сьютами (580 ассертов и 48 кейсов стража) |
| `skills/` | 14 скиллов: инженерный процесс, верификация, тексты, делегирование |
| `agents/` | Adversarial-ревьюер и три линзы `simplify` |
| `commands/` | `/adversarial-review`, `/adversarial-review-internal`, `/checkpoint`, `/rebuild` |
| `reference/` | Документы по требованию — маршрутизация моделей, маршрутизация Codex, устройство конфигурации |
| `output-styles/` | `dense` — плотный стиль ответов, на который рассчитан весь стек |
| `rules/` | Правила с привязкой к путям (UI/UX-правила подгружаются только для фронтенд-файлов) |
| `CLAUDE.md` | Глобальные инструкции, которые принуждают хуки |
| `install.py` | Установщик, со своим сьютом в `test_install.py` (30 ассертов) |

## Три системы хуков

### 1. Code Work Gate

Хук `Stop`, который не даёт сессии закрыться с заявлением «работа сделана», если протокол,
на который она ссылается, наблюдаемо не выполнялся.

Гейт **не выносит суждений**. Он проверяет небольшой набор фактов, которые либо есть в
транскрипте, либо нет:

- скилл `development-verification` был вызван в этой сессии один раз;
- для кандидата высокого риска независимое adversarial-ревью дало вердикт, и этот вердикт
  **новее** последнего изменения долговременного артефакта;
- вердикт пришёл из сессии, которая была проинструктирована ролью ревьюера — напечатать
  строку `VERDICT: APPROVED`, не запуская ревью, не получится;
- кандидат пришёл в терминальное состояние, а не растворился.

Принимаются два движка ревью: внешний **Codex** (основной) и встроенный нативный субагент
`adversarial-reviewer` (фоллбэк). Одна лейна на раунд, никогда обе.

Лейна Codex сверяется с собственными rollout-логами Codex CLI, а не с текстом набранной
команды. Лог читается двоичным поиском по append-only хронологическому файлу, поэтому раунд
ревью из середины многомегабайтного resumed-лога находится без сканирования всего файла.

У гейта **жёсткий предел в три блокировки на неизменившегося кандидата**. Неподчинение
становится явным, но бесконечного цикла не возникает.

```bash
python hooks/test_gate.py
```

### 2. Непрерывность

Сжатие контекста — то место, где длинные задачи тихо теряют свои требования. Шесть хуков
удерживают задачу живой через сжатие, перезапуск и делегирование:

- `continuity_session_start.py` — подставляет чекпоинт текущего каталога при start/resume/clear/compact
- `continuity_prompt.py` — обновляет намерение на каждом ходе пользователя, сбрасывает счётчики цикла
- `continuity_progress.py` — считает применённую правку настоящим прогрессом
- `continuity_loop_guard.py` — считает одинаковые вызовы внутри одной генерации и останавливает штопор
- `continuity_stop.py` — вычищает из финального ответа следы самокоррекции («на самом деле», «как я говорил выше»)
- `continuity_subagent.py` — выдаёт делегированной лейне текущее требование, а не то, которое его заменило

`/checkpoint` показывает, пишет или обновляет чекпоинт вручную.

### 3. Страж плотности комментариев

Хук `PreToolUse` на `Edit|Write`, который отклоняет правку, где код тонет в комментариях или
где в комментарий протекает разговор (`# пользователь просил так`, `# первая попытка
провалилась`, `# до этой правки…`). Детерминированный, локальный, без обращения к модели —
несколько миллисекунд поверх запуска интерпретатора. Русский текст распознаёт тоже.

Отключается на конкретной машине через `CLAUDE_COMMENT_GUARD=off` в блоке `env` файла
`settings.json`.

```bash
python hooks/comment_density_guard_test.py
```

## Скиллы

| Скилл | Когда срабатывает |
|---|---|
| `engineering-workflow` | Перед нетривиальной работой с кодом, конфигурацией, схемой, миграцией или API |
| `development-verification` | Финальные проверки и конечное ревью по риску перед завершением реализации |
| `root-cause-engineering` | Баг, плавающий тест, регрессия, проблема производительности, инцидент |
| `simplify` | Изменённый объём с конкретной претензией к читаемости, переиспользованию, потоку управления или эффективности |
| `current-docs` | Всё, что зависит от версии библиотеки, API, фреймворка или CLI |
| `codebase-memory` | Структурные запросы — символы, вызывающие, цепочки вызовов, влияние изменения |
| `subagent-delegation` | Решение, стоит ли ограниченная лейна отдельного субагента |
| `canonical-state` | Требование изменилось, предстоит передача или один и тот же фикс упал дважды |
| `compact-instructions` | Написание и проверка сводок для сжатия и передачи |
| `local-windows-tooling` | Команды оболочки на Windows |
| `text-quality` | Перед финализацией любого текста, включая коммит-сообщения и комментарии в коде |
| `human-writing` | Проза, которая должна читаться как написанная человеком |
| `claude-code-uiux-design` | Всё, что видит конечный пользователь |
| `codex-imagegen` | Генерация изображений и иллюстраций через Codex |

## Установка

Нужны Claude Code ≥ 2.1.117 и Python 3.11+.

```bash
git clone https://github.com/Negifis/claude-code-stack.git && cd claude-code-stack
```

Сначала посмотрите, что произойдёт: сухой прогон перечисляет каждый файл, который будет
добавлен или заменён.

```bash
python install.py --dry-run
```

Затем установка. Существующие файлы, которые отличаются, перед заменой копируются в
`~/.claude/backups/stack-install-<метка времени>/`:

```bash
python install.py
```

Это записывает `~/.claude/settings.stack.json` с путями хуков, разрешёнными относительно
вашего реального интерпретатора и каталога конфигурации, и не трогает ваш `settings.json`.
Чтобы вместо этого влить хуки автоматически — текущие настройки сначала сохраняются в
бэкап, посторонние ключи не теряются, а повторный запуск не регистрирует хук дважды:

```bash
python install.py --merge-settings
```

Перезапустите Claude Code и убедитесь, что всё работает:

```bash
python hooks/test_gate.py
```

```bash
python test_install.py
```

### Необязательное

- **Лейна ревью Codex.** Основной движок adversarial-ревью. Нужны Node 18.18+, Codex CLI
  (`npm install -g @openai/codex`) и плагин `codex@openai-codex`. Настройка описана в
  `reference/codex-routing.md`. Без него лейну берёт нативный субагент `adversarial-reviewer`
  — гейт принимает любой из движков.
- **MCP `codebase-memory`.** Скилл `codebase-memory` рассчитан на MCP-сервер с графовым
  индексом. Если такого сервера нет, скилл лучше не ставить.

## Конфигурация

В `settings.example.json` два плейсхолдера: `__CLAUDE_DIR__` и `__PYTHON__`. Они намеренно
без кавычек — установщик разбирает команду на аргументы и сам расставляет кавычки так, как
нужно запускающей оболочке. При ручной настройке это придётся сделать самому: закавычить
любой путь с пробелом и экранировать обратные слэши для JSON. Поэтому проще запустить
`install.py` и посмотреть результат в `settings.stack.json` до того, как вливать его.

Что стоит знать до включения:

- У стиля `dense` во фронтматтере обязан оставаться `keep-coding-instructions: true`. Без
  этого флага Claude Code выбрасывает встроенную секцию «Doing tasks», а именно она несёт
  политику отказа от комментариев, на которой держится вся плотность.
- `CLAUDE.md` ставится, только если своего у вас ещё нет. Иначе сливайте вручную.
- Список разрешений намеренно **не** поставляется. Разрешения — личная вещь, а чужой
  список разрешений это дыра в безопасности.
- Хук автообновления плагинов написан на PowerShell, поэтому регистрируется только на
  Windows. Всё остальное в составе — Python и работает везде.
- Установщик отказывается от пути, который не может безопасно закавычить для запускающей
  оболочки: на Windows это значит никаких `%` и `"` в пути.

## Что не включено

Сторонние скиллы, которые жили рядом с этим стеком, остались за бортом: они принадлежат своим
авторам, и ставить их лучше из первоисточника.

- [avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing) — MIT
- [anti-ai-rhetoric](https://github.com/matteoroversi/anti-ai-rhetoric)
- [drawio-skill](https://github.com/Agents365-ai/drawio-skill) — MIT
- [geo-seo-claude](https://github.com/zubair-trabzada/geo-seo-claude) — семейство GEO/SEO-скиллов
- [claude-skill-tilda](https://github.com/JHamidun/claude-skill-tilda)
- [notebooklm-cli](https://github.com/jacob-bd/notebooklm-cli) — MIT, вместе с ним ставится скилл `nlm-skill` для NotebookLM
- маркетинговый пак `superamped` (реклама, разведка конкурентов, контент-стратегия)
- встроенные скиллы Anthropic — `playwright`, `webapp-testing`, `theme-factory`
- скиллы Figma — `figma`, `figma-implement-design`, `figma-create-design-system-rules`

Также не вошёл мост памяти NotebookLM, на который ссылалась прежняя версия `CLAUDE.md`: он
зависит от инструментов, которых здесь нет.
